# Shaam-e-Awadh

A family menu of vegetarian dishes, from everyday home-cooked meals to Lucknowi specialties.

## View it

Once GitHub Pages is on, the site lives at `https://<github-username>.github.io/shaam-e-awadh/`.

## Edit the menu

All dishes are in the `MENU` list at the top of the script in `index.html`. Add, remove or move a dish inside its group. Counts and numbering update on their own.

## Main course

The main course section holds 51 everyday dinner options, including dals and legumes. The goal is familiar dishes the whole family already eats, not new combinations.
